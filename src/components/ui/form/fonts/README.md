# Polices du kit de formulaire

## TwemojiCountryFlags.woff2

Drapeaux des pays pour `<PhoneInput>`, utilisés uniquement sur les systèmes qui
n'affichent pas les drapeaux émoji (Windows). Fichier repris du paquet
[`country-flag-emoji-polyfill`](https://github.com/talkjs/country-flag-emoji-polyfill)
0.1.10 (TalkJS), sans modification.
